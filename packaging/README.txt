DanceDNS — портативный DNS-клиент для Windows (DNS-over-QUIC / DNS-over-HTTPS)
=============================================================================

Установка не нужна.

1. Положите dancedns.exe в любую папку (рабочий стол, флешка).
2. Запустите его и подтвердите запрос прав администратора.
3. Появится окно DanceDNS и значок в трее. Защита включается сама:
   весь DNS Windows идёт через DNS-over-QUIC (AdGuard DNS / Control D).
4. Закрытие окна сворачивает DanceDNS в трей.
   Выход: правой кнопкой по значку в трее → «Выход». Прежние настройки DNS вернутся.

Рядом с программой появятся файлы:
  dancedns.yaml      — настройки и правила (кнопка «Настройки…», применяются после сохранения)
  dancedns.log       — журнал работы
  WinDivert.dll,
  WinDivert64.sys    — драйвер перехвата DNS-запросов, которые идут мимо системных настроек

Если программа была закрыта аварийно и интернет не работает, выполните в командной строке
(от имени администратора):
    dancedns.exe --restore-dns
